# Контракт Tool

`Tool.run(transcript) → ToolResult` запускается Dispatcher для выбранного режима. На входе непустой список реплик в порядке времени начала. У каждой реплики есть `startMs` (целое неотрицательное число) и `text` (непустая строка).

Адаптер проверяет внешний ответ, сортирует реплики и передаёт Dispatcher нормализованные данные. Dispatcher выбирает Tool через Registry и передаёт ему только нормализованные реплики. Tool защищает границу своего интерфейса и возвращает `INVALID_TRANSCRIPT` для пустого списка, неверного типа, пустого текста или некорректных таймкодов. При невозможности построить результат Tool возвращает `ANALYSIS_FAILED`. Dispatcher сохраняет обе ошибки как `FAILED / ANALYSIS_FAILED`, результат отсутствует.

| Tool | Режим | Успешный результат |
|---|---|---|
| `BriefSummaryTool` | `brief` | `{points: string[]}`, непустой список тезисов |
| `TimelineDigestTool` | `timeline` | `{segments: {startMs: integer, points: string[]}[]}`, непустой список отрезков в порядке начала. У каждого отрезка есть таймкод из субтитров и хотя бы один тезис. |

Tool возвращает только результат или ошибку. Состояние Job и сохранение результата контролирует Dispatcher.
