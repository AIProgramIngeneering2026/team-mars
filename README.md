# team-mars
## Пересказ YouTube-роликов по субтитрам

Длинный ролик приходится смотреть целиком, чтобы понять, есть ли в нём нужная информация. Сервис помогает студентам и зрителям обучающих видео быстро понять содержание ролика и найти нужный фрагмент.

### Что входит в первую версию

- Пользователь вставляет ссылку на общедоступный ролик YouTube и выбирает один из двух режимов. По умолчанию включён краткий пересказ.
- **Краткий пересказ** возвращает ключевые тезисы из субтитров.
- **Таймлайн** делит ролик на отрезки и показывает время начала и основные тезисы каждого отрезка.
- Сервис создаёт задачу обработки (Job). По её идентификатору можно посмотреть статус, получить результат или отменить обработку.
- Если субтитры недоступны или источник не отвечает, сервис показывает причину сбоя.

За рамками первой версии остаются скачивание видео, распознавание аудио, поддержка других видеоплатформ и ответы на свободные вопросы о ролике.

### Как устроена обработка

Запрос создаёт `Job` с выбранным режимом. `Dispatcher` получает субтитры через адаптер и выбирает исполнителя в `Registry`. Два исполнителя, `BriefSummaryTool` и `TimelineDigestTool`, работают через общий контракт `Tool` и возвращают `ToolResult`. Для тестов адаптер отдаёт заранее подготовленные субтитры с таймкодами.

Поставщика субтитров предстоит выбрать. Для первой версии тезисы можно извлекать из самих субтитров простыми правилами. Модель можно подключить позже внутри исполнителя, сохранив контракт `Tool`.

### Реализация S1

Ветка S1 содержит приём URL, Job, Dispatcher, Registry, два Tool и хранение результата. Каждое новое действие с новым ключом создаёт Job в `CREATED`. Повтор того же ключа возвращает исходный ID. Повторное использование готовых результатов S5 добавляет другой участник команды.

Используются Python 3.9+ (рекомендуется Python 3.12 с OpenSSL), SQLite и один фоновый исполнитель. Во время анализа Tool запускается в отдельном процессе и останавливается при превышении 60 секунд. Тезисы извлекаются простыми правилами: до пяти первых уникальных предложений, таймлайн группируется по минутам. Конкретный стек и алгоритмы подлежат ревью команды.

#### Установка и запуск

Из корня репозитория:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
source .env.example
python -m mars
```

Без `MARS_TRANSCRIPTS` сервис получает публичные субтитры через `youtube-transcript-api`. Предпочтение отдаётся русскому и английскому языку, затем доступному языку из списка источника. Сетевые запросы ограничены таймаутом и размером ответа. Ошибки источника преобразуются в коды `TRANSCRIPT_*`. Повторы сетевых запросов S3 остаются отдельной задачей.

Для детерминированной проверки без сети перед запуском укажите:

```sh
export MARS_TRANSCRIPTS=tests/fixtures/transcripts.json
python -m mars
```

В этом режиме демонстрационный ID `abcdefghijk` относится к тестовым данным.

#### Проверка S1

В другом терминале создать Job:

```sh
curl -i http://127.0.0.1:8000/jobs \
  -H 'Authorization: Bearer local-demo-token' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: first-brief' \
  -d '{"url":"https://youtu.be/abcdefghijk","operation":"brief"}'
```

Ответ `202` содержит ID и `Location`. Прочитать текущее состояние и результат:

```sh
curl http://127.0.0.1:8000/jobs/ID_ИЗ_ОТВЕТА \
  -H 'Authorization: Bearer local-demo-token'
```

Для таймлайна отправьте новый ключ и режим `timeline`. Для реального YouTube-ролика отключите `MARS_TRANSCRIPTS` перед запуском и замените ссылку. При недоступных субтитрах Job завершится с ошибкой, доступной через GET.

Тесты обоих режимов, HTTP, конкурентных повторов, восстановления и адаптера запускаются без обращения к YouTube:

```sh
python -m unittest discover -s tests -v
```

#### Границы интеграции

- Получение субтитров отделено протоколом `TranscriptSource.get(video_id)`. Внешние таймкоды переводятся в целые миллисекунды, реплики сортируются с сохранением порядка равных таймкодов.
- Проверка URL, создание Job и чтение результата доступны через `JobService`. Это точка подключения S5.
- Результат Tool проверяется Job перед сохранением: форма соответствует режиму, тезисы непусты, таймкоды упорядочены, уникальны и взяты из входа.
- SQLite сохраняет Job и результат между перезапусками. Просроченное право обработки приводит к `PROCESSING_INTERRUPTED`. Отмена защищена от запоздавшего результата.
- Запуск использует один токен из окружения. Многопользовательскую аутентификацию и интеграцию с общим инфраструктурным каркасом необходимо согласовать с командой.
- Поддерживается домен `youtube.com` без `www`, что требуется примерам сценариев. Перечень доменов нужно синхронизировать с OpenAPI в задаче #13.
- Локальный HTTP-сервер слушает только `127.0.0.1`. Публичное развёртывание требует отдельной настройки сервера.
