# team-mars
## Пересказ YouTube-роликов по субтитрам

Длинный ролик приходится смотреть целиком, чтобы понять, есть ли в нём нужная информация. Сервис помогает студентам и зрителям обучающих видео быстро понять содержание ролика и найти нужный фрагмент.

### Что входит в первую версию

- Пользователь вставляет ссылку на общедоступный ролик YouTube и выбирает один из двух режимов. По умолчанию включён краткий пересказ.
- **Краткий пересказ** возвращает ключевые тезисы из субтитров.
- **Таймлайн** делит ролик на отрезки и показывает время начала и основные тезисы каждого отрезка.
- Сервис создаёт задачу обработки (Job). По её идентификатору можно посмотреть статус, получить результат или отменить обработку.
- Если субтитры недоступны или источник не отвечает, сервис показывает причину сбоя.

За рамками первой версии остаются скачивание видео, распознавание аудио, поддержка других видеоплатформ и ответы на свободные вопросы о ролике.

### Как устроена обработка

Запрос создаёт `Job` с выбранным режимом. `Dispatcher` получает субтитры через адаптер и выбирает исполнителя в `Registry`. Два исполнителя, `BriefSummaryTool` и `TimelineDigestTool`, работают через общий контракт `Tool` и возвращают `ToolResult`. Для тестов адаптер отдаёт заранее подготовленные субтитры с таймкодами.

Поставщика субтитров предстоит выбрать. Для первой версии тезисы можно извлекать из самих субтитров простыми правилами. Модель можно подключить позже внутри исполнителя, сохранив контракт `Tool`.
